## 11. FLUJO COMPLETO DE UNA VENTA CON FACTURACIÓN ELECTRÓNICA

Describe paso a paso el flujo esperado:

1. El usuario inicia sesión.
2. Accede al punto de venta.
3. Busca y agrega productos.
4. El sistema valida precios y stock.
5. Selecciona o registra al cliente.
6. Selecciona el tipo de comprobante.
7. El sistema calcula los importes y los impuestos.
8. Registra la operación mediante una transacción controlada.
9. Procesa el pago según las reglas del negocio.
10. El backend construye la solicitud conforme al contrato real de API-PRO.
11. El backend envía la solicitud a la API.
12. Se interpreta la respuesta.
13. Se actualiza el estado del comprobante.
14. Se registra la trazabilidad del proceso.
15. Se permite consultar o descargar los documentos disponibles.
16. Se actualizan los reportes y el inventario sin duplicar movimientos.

Analiza también qué sucede cuando:
- La API rechaza el comprobante.
- La solicitud agota el tiempo de espera.
- La conexión se pierde después de enviar la solicitud.
- El usuario intenta emitir dos veces.
- El pago se registra, pero la emisión queda pendiente.
- SUNAT devuelve observaciones.
- Se necesita emitir una nota de crédito.

No asumas que una operación es reversible. Define los estados y procedimientos de recuperación según las capacidades reales de la API.
